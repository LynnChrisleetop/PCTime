# 0.1.0 跨设备版本验证记录

验证日期：2026-09-23。开发分支：`codex/cross-device-screen-time`。

## 已完成

- Windows / Web：TypeScript 类型检查、ESLint 和 88 项自动化测试通过。覆盖原有本地记录功能、云端账号隔离、会话、快照替换、离线重试、应用合并及账号切换。
- 同步服务：18 项真实 HTTP 测试通过，使用独立的临时 SQLite 数据库验证持久化、重复 / 旧快照、非法输入和跨用户访问限制。
- Windows 同步集成：真实 HTTP / SQLite 服务联调通过；另在 Electron 30 和 Windows `safeStorage` 运行时验证加密保存、进程重建后恢复与退出账号。没有将明文令牌、密码或窗口标题写入云同步日志。
- 页面交互：真实测试服务下验证登录、日期切换、设备筛选、应用展开和退出账号。示例中电脑微信 10 分钟、哔哩哔哩 5 分钟，手机微信 10 分钟、哔哩哔哩 15 分钟，合计 40 分钟，微信合计 20 分钟；仅选电脑时合计 15 分钟。
- 页面布局：检查 1280 px 和 390 px 宽度，无横向溢出；保留已选的 A 版浅蓝时长卡及局部跳色。
- Windows：生成 64 位 ZIP，压缩包完整性检查通过。界面编译和 Electron 同步运行时验证分别执行；没有把它们当作打包程序的完整人工验收。
- Android：纯 Java 时间重建测试通过，涵盖跨午夜、锁屏、灭屏、快速切换、同包 Activity 切换、重复事件、断点接续、夏令时、时钟回拨和关机重启。
- Android：`assembleDebug`、`lintDebug` 和 APK 签名验证通过。Lint 为 0 错误、7 条中文文案国际化警告。APK 使用 v2 签名，包名 `com.pctime.android`，版本 `0.1.0`，最低 API 26，目标 API 35。
- Android 工具链安装脚本在本地执行通过，固定下载文件的 SHA-256；SDK 许可由用户明确授权接受。

## 仍需实际使用验证

- 当前没有连接 Android 手机或运行模拟器，尚未验证真机权限引导、厂商省电策略、后台调度和实际使用事件的完整性。
- Android 构建是个人试用的 debug APK；Windows ZIP 未签名。正式分发签名、品牌名和图标尚未确定。
- 同步服务只在本机测试环境联调；没有开通或部署公共服务，也没有运行 Docker 部署示例。跨网络同步需要自行部署可访问的 HTTPS 服务。
- 首版暂不提供邮件验证、找回密码、账号删除或远程设备删除。
- Windows 历史数据继续在原页面查看，跨设备记录从新版本开始。Android 首次采集和长期停用后的补采受系统事件保留时间限制。

安装和连接步骤见 [跨设备使用指南](cross-device-guide.md)。构建产物位于本地 `release/0.1.0/`，不提交到 Git。
