# 安装后，直接开始记录

本机统计不需要注册账号、填写服务器地址、安装 Node.js 或运行命令。

## Windows

1. 双击 `PCTime-Setup-0.1.1.exe`，应用会安装到当前用户目录，并创建桌面和开始菜单入口。
2. 安装完成后打开 PCTime，直接查看「概览」。应用运行时会自动记录使用时长，首次使用需要积累一些记录。
3. 日常从桌面的 PCTime 图标打开。已有统计数据会保留；关闭窗口后的行为可在偏好设置中调整，退出应用会停止记录。

安装包已包含运行所需的程序，无需解压后挑选文件，也无需安装开发工具。这是尚未配置发布者签名的试用版，Windows 可能显示发布者未知提示。

## Android

1. 将 `PCTime-Android-0.1.1-debug.apk` 传到手机，点击安装。支持 Android 8.0 及以上；系统可能要求允许当前文件管理器安装应用。
2. 打开 PCTime，点击「打开使用情况访问权限」，在系统设置中允许 PCTime，然后返回应用。这一步由 Android 系统要求，应用无法代替你授权。
3. 应用默认显示「本机离线记录」，点击「刷新记录」即可查看这台手机的统计。高级设置默认收起，无需填写账号与服务器。

Android 当前为测试版，厂商省电策略和后台记录效果仍需真机验证。

## 想把两台设备合在一起看

这一步是可选的，不影响上面的本机记录。当前版本的账号同步需要连接已经运行的同步服务；安装包尚未内置公共在线服务。

已经有同步服务时，两端登录同一账号即可查看总时长、单台设备，以及微信、哔哩哔哩等应用的合计。自行部署的详细步骤放在 [跨设备连接说明](cross-device-guide.md)，普通本机使用无需阅读。
