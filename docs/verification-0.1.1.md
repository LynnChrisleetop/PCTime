# 0.1.1 安装体验验证

本次只调整安装方式、首次使用入口及说明，计时和同步协议保持原有实现。

- Windows：生成 `PCTime-Setup-0.1.1.exe`，约 77 MiB。NSIS 构建成功，安装器内嵌压缩数据完整性检查通过，文件版本确认为 0.1.1。同时保留 ZIP 便携包，其完整性检查通过。
- 安装器配置：当前用户安装、桌面和开始菜单快捷方式、完成后启动、卸载保留用户数据。未在本机执行安装和卸载流程，避免影响已有安装与快捷方式。
- 修正原有 `win.sign: false` 配置：electron-builder 24 将非空的 `sign` 当作自定义签名器入口，导致 NSIS 在没有证书时错误进入签名流程；删除该字段后，按未配置证书的正常流程生成试用包。
- Windows 页面：TypeScript 和 ESLint 通过；浏览器检查确认账号表单默认折叠，点击高级设置后可正常展开。桌面端新增返回本机记录按钮，概览为第一项导航。
- Android：`assembleDebug`、`lintDebug` 成功，0 错误、7 条中文文案国际化警告；APK v2 签名验证通过，版本号升至 0.1.1 / versionCode 2。权限入口前移，账号表单默认收起，未登录时按钮显示「刷新记录」。
- 没有连接 Android 真机，权限、安装升级和厂商后台策略仍待实测。Windows 安装包尚未配置发布者证书，Android 是 debug 测试包。
- 按用户选择，本次先交付安装版；统一在线服务下一步再部署。当前不承诺安装后即可跨网络登录同步，本机统计无需账号和服务器。

原有计时、账号和同步逻辑的自动化验证见 [0.1.0 验证记录](verification-0.1.0.md)。安装器配置依据 [electron-builder NSIS 文档](https://www.electron.build/nsis/) 和本地版本实现。
