# Windows + Android 跨设备使用指南

只想安装后记录本机时间，请看 [安装与开始记录](quick-start.md)，无需完成下面的服务器配置。本页用于连接多台设备和自行部署同步服务。

这一版使用 PCTime 作为临时名称，提供可运行的 Windows 客户端、Android 应用，以及自行部署的账号同步服务。尚未提供公共托管服务；两端填写同一个服务地址、登录同一个账号即可关联。

## 先在电脑上启动同步服务

需要 Node.js 24。项目目录下运行：

```powershell
npm run server
```

默认地址为 `http://127.0.0.1:4318`，仅这台电脑可以访问。数据写在 `server/data/pctime.sqlite`，重启服务不会丢失账号和统计。访问 `/healthz` 可检查服务是否运行。

手机与电脑处于同一局域网时，先停止上面的服务，再运行：

```powershell
$env:PCTIME_HOST = '0.0.0.0'
npm run server
```

电脑可以继续填写 `http://127.0.0.1:4318`，手机填写电脑的局域网 IPv4 地址，例如 `http://192.168.1.20:4318`。手机的 `127.0.0.1` 指手机自身，不能用来连接电脑。若防火墙阻止连接，仅为受信任的专用网络放行端口 4318。电脑休眠、服务关闭或两端不在同一网络时，局域网服务不可达，本地记录会保留。

要在不同网络下长期同步，需要将 `server/` 部署到一直在线的主机，使用 HTTPS 域名。客户端只允许公网 HTTPS，HTTP 仅用于本机或私有局域网 IP。部署、容器、持久化及备份详见 [服务说明](../server/README.md)。此项目不会自动开通收费云资源。

## Windows

1. 双击 `release/0.1.1/PCTime-Setup-0.1.1.exe` 安装，之后从桌面的 PCTime 图标打开。若使用 ZIP 便携版本，解压后运行里面的 `PCTime.exe`，保留同目录资源。
2. 打开“跨设备”，填写同步服务地址、邮箱、至少 10 个字符的密码，以及设备名称。
3. 首次使用选择“创建账号”；已有账号直接登录。注册即创建会话，不发送验证邮件。此版本暂不支持找回密码，请保存好密码。
4. 登录后自动同步，运行期间约每分钟尝试一次；也可点“立即同步”。收起到托盘后仍可记录，退出应用则停止记录。

原有电脑历史继续在“概览 / 明细”查看。跨设备记录从这一版开始独立采集，避免以前导入的 WebDAV 数据重复计入。退出账号停止上传，但保留本机统计；再次登录可继续同步。

## Android

1. 将 `release/0.1.1/PCTime-Android-0.1.1-debug.apk` 传到 Android 8.0 或更新系统的手机，安装测试版。
2. 按页面提示进入系统设置，允许 PCTime 的“使用情况访问”。无需无障碍权限。
3. 填写相同的同步服务地址，登录 Windows 上创建的账号，设置容易区分的设备名。
4. 点击同步，查看全部设备、单台设备和应用合计；点应用可查看各设备贡献。

后台同步由 Android 调度，最短周期为 15 分钟，可能被省电策略延迟，并非实时推送。打开应用或手动同步可以立即刷新。厂商后台限制、强制停止、长期不运行或系统清理旧使用事件，可能导致无法补齐较早记录；应用会显示相关状态。日常需要允许应用按系统设置在后台运行。

APK 是用于试用的 debug 构建，不是商店发布包。不要卸载再安装来测试升级，否则本地设备身份会变化，服务端会视为另一台设备。应用名称、图标、正式签名及商店发布后续再确定。

## 统计规则

- 各设备累加：同时用电脑 10 分钟、手机 10 分钟，合计 20 分钟。这是设备使用总量。
- 每台设备以当地日期归档；跨时区旅行时，同一个日历日期可能覆盖不同的实际时间区间。
- 微信、哔哩哔哩、QQ 的已知 Windows / Android 标识合并为一行；其他应用保留平台区分，避免误合并。
- Windows 浏览器只有明确匹配哔哩哔哩品牌标题时才归入哔哩哔哩。Android 统计原生应用，浏览器中的网站仍算浏览器时间。
- 服务接收完整的每日应用快照，较旧或重复版本不会再次累加。
- Windows 锁屏、休眠、空闲超过 60 秒不计时；Android 按系统前台应用与屏幕事件重建。不同平台的活跃判定有差异。

## 数据与账号

跨设备上传包含应用名称/标识、时长、日期/时区、设备名称，不上传电脑窗口标题。Windows 会话由系统安全存储加密，Android 会话由 Keystore 加密，客户端不保存密码。服务器保存密码派生值及令牌摘要，会话 30 天到期。

本地 Windows 原始统计和现有 WebDAV 仍可能包含窗口标题。原有 WebDAV 设置包含其连接凭据，请不要公开数据目录。WebDAV 备份和跨设备同步相互独立。

如需备份服务，先停止服务，再复制整个 `server/data/` 目录，包括可能存在的 SQLite WAL/SHM 文件。数据库本身没有加密，应保存在有合适权限的磁盘上。退出账号只撤销当前会话，并不删除服务器上的历史统计。

## 开发验证

```powershell
npm ci
npm run typecheck
npm run lint
npm test
npm run build
```

Android 工具链及构建命令见 [Android 说明](../android/README.md)。服务测试使用隔离的临时数据库，Windows 集成测试通过真实 HTTP 调用服务，预览演示数据不会写入真实用户记录。

安装体验的验证结果见 [0.1.1 验证记录](verification-0.1.1.md)，计时与同步验证见 [0.1.0 验证记录](verification-0.1.0.md)。

浏览器查看模式：启动 `npm run dev:web`，访问 `http://127.0.0.1:5173/?cloud=1`。启动服务前设置 `$env:PCTIME_ALLOWED_ORIGINS = 'http://127.0.0.1:5173'`。只允许精确来源，不需要为原生 Windows/Android 客户端设置 CORS。
